MOAT CAIRN MULTI-PAGE MULTILINGUAL STARTER

Included files:
- index.html, services.html, portfolio.html, pricing.html, contact.html
- demos/restaurant.html, demos/clothing.html, demos/property.html
- assets/styles.css, assets/site.js

Features:
- Multiple pages with shared navigation.
- English, French, and Arabic language switch.
- Arabic right-to-left layout.
- Currency selector for EUR, USD, GBP, DZD, and CAD.
- CSS-only placeholder image areas. No image files were created or included.

PUBLISH TO YOUR EXISTING GITHUB REPOSITORY
Repository: https://github.com/Adomdumdum/test
1. Download and extract this ZIP.
2. Open the repository in GitHub.
3. Upload/replace the files while preserving the exact structure. The assets and demos folders must sit beside index.html in the repository root.
4. If using mobile and uploading the ZIP contents is difficult, create files one by one with Add file > Create new file and enter exact paths like assets/styles.css or demos/restaurant.html.
5. Commit changes to branch main.
6. Check https://github.com/Adomdumdum/test/settings/pages: deploy from main and /(root).
7. Visit https://adomdumdum.github.io/test/ and test navigation, language, currency, and Arabic layout.

The language/currency preferences are saved in the visitor's browser only. This is still a static website, not the secure multi-client platform.

LIMITATIONS
No secure client accounts, database, private dashboard, payment processing, backend form submission, automatic client subdomains, or server-side tenant isolation are included. The email button opens the visitor's email app. Do not place passwords, secret API keys, or private client data in this repository.
